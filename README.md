
Heart Disease Prediction (Machine Learning Project)

This project predicts the likelihood of heart disease using patient medical data and machine learning techniques.

Technologies

Python, Pandas, NumPy

Matplotlib, Seaborn

Scikit-learn (Logistic Regression, Decision Tree, Random Forest)

 Data Overview

297 patients × 14 medical features

Target: 1 = Heart disease, 0 = No disease

regarding the Model Results:
in Logistic Regression the Accuracy rate was 0.95 , in Decision Tree accuracy rate was 0.78 , in Random Forest the accuracy rate was 0.88 , in Optimized Random Forest it was 0.87.

Key Insights:

1- cp, thalach, and age are the most important predictors.

2- Older patients with chest pain and low heart rate have higher heart disease risk.
